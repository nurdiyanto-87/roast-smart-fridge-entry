# Roast the Smart Fridge: One Line, Best Laugh Wins

One roast line (≤160 characters) for the make.fun bounty
**"Roast the Smart Fridge: One Line, Best Laugh Wins"** — a single line
roasting the smart fridge I share a house with. `main.py` (pure Python
standard library, no third-party dependencies) writes the line to
`/output/entry.txt`.
